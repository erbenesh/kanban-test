# Kanban-доска задач

Клиентская доска из четырёх колонок: To Do, In Progress, Review и Done. Сервера нет: стартовые задачи лежат в репозитории, а изменения сохраняются в `localStorage` браузера.

## Технологии

- React 19 и TypeScript 5.9
- Webpack 5: точка входа `src/index.html`, CSS и CSS Modules собирает сам Webpack
- Vitest 3 для unit-тестов
- Состояние доски: React Context и один `useReducer`

В зависимостях приложения только `react` и `react-dom`. Сборщик, типы и тесты стоят в `devDependencies`.

## Требования к окружению

- Node.js не ниже **18.18.0** (`engines` в `package.json`)
- npm, который идёт с этой версией Node.js
- Современный браузер с поддержкой CSS `url()` для WebP

Шрифт Inter подключается с Google Fonts. Без сети страница открывается с запасным `system-ui`.

## Установка зависимостей

```bash
npm install
```

## Запуск

```bash
npm run start
```

Dev-сервер Webpack слушает `http://127.0.0.1:3000`.

## Сборка

```bash
npm run build
```

Production-сборка попадает в каталог `dist/`.

## Тесты

```bash
npm run test
```

Команда запускает `vitest run`. Файлы тестов лежат рядом с кодом: `*.test.ts` и `*.test.tsx`.

## Основной функционал

- Четыре колонки и карточки со сроками и описанием.
- Создание задачи кнопкой «+ Добавить» в колонке To Do. В форме можно выбрать любую из четырёх колонок.
- Редактирование и удаление с карточки. Удаление спрашивает подтверждение.
- Поиск по всем колонкам. Строка из текста ищет подстроку в описании без учёта регистра. Строка в формате `дд.мм.гггг` ищет задачи, у которых в этот календарный день по UTC приходится начало или окончание. Пустой запрос показывает все задачи. Если совпадений нет, колонки остаются пустыми.
- Сортировка карточек внутри колонки по дате начала, по возрастанию.
- Просроченные задачи: окончание раньше текущего дня UTC и статус не Done. Дата окончания подсвечивается красным.
- Перенос задачи в другую колонку мышью.
- Сохранение списка задач в `localStorage` под ключом `kanban_tasks`. После перезагрузки показывается сохранённый список. Если запись отсутствует или не проходит проверку, доска берёт `src/data/tasks.json`.

## Архитектура

| Каталог | Роль |
| --- | --- |
| `src/app` | Экран `App`, `TaskProvider`, `taskReducer`, запись в `localStorage` |
| `src/shared/lib` | Правила доски без React: даты, фильтр, сортировка, просрочка, черновик задачи |
| `src/shared/ui` | Колонка, карточка и форма. Столбцы сами не пересчитывают |
| `src/data` | Стартовый список `tasks.json` и чтение через `tasks.ts` |

Импорты идут от `src/app` к `src/shared` и `src/data`. UI может брать типы и чистые функции из `src/shared/lib`. Обратно `shared` в `app` не импортирует.

Поисковый запрос хранится в `App` и на список в контексте не записывается. Reducer меняет только список задач: добавить, изменить, удалить, сменить колонку.

## Drag & Drop

Перенос сделан нативным HTML5 Drag and Drop, без отдельной библиотеки.

Карточка в режиме просмотра перетаскивается мышью. В `dataTransfer` кладётся только числовой `id`. Колонка при отпускании вызывает `moveTask`: меняется статус, текст и даты остаются. Пустая колонка тоже принимает карточку.

У перетаскиваемой карточки синяя рамка и пониженная непрозрачность. У колонки под курсором синяя внутренняя рамка. Если отпустить карточку мимо колонки или отменить жест, статус не меняется. Повторное отпускание в ту же колонку тоже ничего не записывает.

Кнопки, поля и форма не начинают перетаскивание. Поле поиска не принимает drop, чтобы идентификатор задачи не попал в запрос.

Порядок внутри колонки после переноса снова задаёт сортировка по дате начала, а не место, куда отпустили карточку.

Клавиатурное перетаскивание и перетаскивание касанием не реализованы.

## Известные ограничения

- Нет бэкенда и общей базы между браузерами. Живёт только `localStorage` текущей вкладки-источника.
- Поисковый запрос после перезагрузки не сохраняется.
- Запрос, который целиком является корректной датой, ищет по датам, а не по тексту описания.
- Даты разбираются как календарные дни UTC в формате `дд.мм.гггг`. Дата окончания не может быть раньше даты начала.
- Карточки внутри колонки нельзя расставить вручную.
- На ширине меньше 768px страница сохраняет минимальную ширину 768px и прокручивается по горизонтали. Отдельной мобильной вёрстки нет.
- Перетаскивание с клавиатуры и с сенсорного экрана не поддерживается.
